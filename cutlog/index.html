Connect your private coach repo

This page holds no health data. It reads app/data.json from your private GitHub repo with a token that stays on this phone only.

Make a read-only token (once)

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → health.
  3. Permissions → Repository → Contents: Read-only. Nothing else.
  4. Expiration: 90 days is a good balance. Copy the token.
